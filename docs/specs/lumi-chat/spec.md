# LUMI Chat

## User-visible outcome

사용자가 카테고리를 선택한 상태에서 LUMI를 호출하면, 그 카테고리에 모아둔 뉴스를 근거로 실제 AI가 답하는 대화창이 열린다.

## Approved scope

- 왼쪽 컬럼에 LUMI 카드(아바타 + "LUMI 호출" 버튼)를 추가한다.
- "LUMI 호출"을 누르면 채팅 모달이 열리고, 현재 선택된 카테고리에서 수집된 뉴스 목록(제목·정리본·링크)을 컨텍스트로 서버에 설치된 `claude` CLI에 전달해 답한다.
- 채팅 모달은 `design/lumi_chat_preview.html`의 레이아웃(왼쪽 아바타 + 연결된 문서 수, 오른쪽 대화 말풍선 + 입력창)을 따른다.
- 연결된 문서 수는 디자인의 고정 숫자 대신, 실제 현재 카테고리의 뉴스 항목 개수를 그대로 보여준다.
- 카테고리를 선택하지 않았거나 뉴스가 없으면, LUMI 호출 시 그 사실을 안내한다.
- `claude` CLI를 찾을 수 없으면(즉, 로컬 실행이 아니면) 채팅 입력 대신 "로컬 실행 시에만 사용 가능" 안내를 보여주고, 실제 대화는 진행하지 않는다.

## Acceptance criteria

- [ ] 카테고리를 선택하고 뉴스가 수집된 상태에서 "LUMI 호출"을 누르면 채팅 모달이 열린다.
- [ ] 모달에는 현재 카테고리에서 수집된 뉴스 개수가 실제 값으로 표시된다.
- [ ] 질문을 입력해 보내면, 그 카테고리 뉴스의 제목·정리본·링크를 근거로 한 실제 응답이 대화창에 표시된다.
- [ ] 카테고리가 선택되지 않았거나 뉴스가 없는 상태에서 LUMI를 호출하면, 대화 대신 안내 문구가 표시된다.
- [ ] `claude` CLI를 사용할 수 없으면(로컬 실행이 아니면), 채팅 입력 대신 "로컬 실행 시에만 사용 가능" 안내가 표시되고 에러 없이 동작한다.
- [ ] 모달은 닫기 버튼이나 배경 클릭으로 닫힌다.

## Settled constraints and rationale

- 채팅의 그라운딩 지식은 이번엔 별도 DB 없이, 현재 카테고리에 수집된 뉴스 목록을 그대로 컨텍스트로 사용한다 — [docs/decisions/lumi-chat-grounding.md](../../decisions/lumi-chat-grounding.md) 참고.
- 답변은 OpenAI/Anthropic API가 아니라, 서버 환경에 설치·로그인된 `claude` CLI를 헤드리스로 실행해 생성한다 — [docs/decisions/local-claude-cli-runtime.md](../../decisions/local-claude-cli-runtime.md) 참고. (OpenAI API는 결제 크레딧이 없어 `insufficient_quota`로 막혔고, ChatGPT/Claude 소비자 구독은 API 플랫폼 결제와 별개라 대신할 수 없었다.)
- 개인용 단일 사용자 도구이며 대화 기록은 여러 기기에서 공유되지 않는다(PRODUCT.md 경계 계승).

## Assumptions

- 채팅은 현재 선택된 카테고리 하나에 스코프된다(여러 카테고리를 넘나드는 통합 대화는 다루지 않음).
- 대화 기록은 모달을 닫으면 사라지는 세션 한정 상태로 유지한다(영구 저장하지 않음).
- LUMI 카드와 채팅 모달의 시각 스타일은 `design/lumi_chat_preview.html`·`design/dashboard_preview.html`을 따른다.
- `claude` CLI 호출 시 도구 사용은 모두 비활성화하고(`--disallowedTools`), 임시 디렉터리에서 실행해 프로젝트 파일에 접근하지 않는다.

## Off-limits (and why)

- 논문·축적 문서 기반 지식 DB(벡터 검색 등) — 사용자가 이후 확장하고 싶다고 밝혔지만, 이번 슬라이스는 뉴스 컨텍스트만으로 좁혀 검증 가능하게 유지한다.
- 여러 카테고리를 넘나드는 통합 대화나 대화 기록 영구 저장 — 단일 카테고리 스코프가 검증된 뒤 다룬다.
- 연구 동향 그래프, 기술 동향 진행 단계, 하단 독 내비게이션 — 여전히 이번 슬라이스 밖.

## Deferred

- 논문 정보나 축적되는 문서 기반의 실제 지식 DB(벡터 검색 등)로 그라운딩을 확장하는 것은 사용자가 명시적으로 다음 단계로 원한 방향이며, 이 슬라이스가 검증된 뒤 별도로 다룬다.
- 여러 카테고리 통합 대화, 대화 기록 저장은 이후 논의한다.
- 정식 API 키(OpenAI/Anthropic) 기반 방식으로 되돌리는 것은, 이 앱을 `claude` CLI가 없는 환경에 배포해야 할 때 다시 논의한다.

## Remaining risks

- 이 방식은 `claude` CLI가 설치·로그인된 환경에서만 동작한다. 일반적인 클라우드 호스팅에 배포하면 CLI가 없어 채팅 기능이 동작하지 않는다 — 로컬 개발 환경 검증에 한정된 제약이다.
- CLI 프로세스 호출은 API 호출보다 느릴 수 있고(수 초 단위), 응답 시간이 일정하지 않을 수 있다.
- 카테고리의 뉴스 항목이 많아지면 컨텍스트로 전달하는 프롬프트 길이가 늘어나 응답 속도에 영향을 줄 수 있다.
