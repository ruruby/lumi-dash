# Keyword News Digest

## User-visible outcome

사용자가 카테고리를 만들고 그 안에 관심 키워드를 추가하면, 카테고리에 등록된 키워드들과 관련된 실제 뉴스가 링크와 정리본(요약)이 달린 목록으로 자동으로 모여 화면에 뜬다.

## Approved scope

- 카테고리를 추가·선택하고, 선택한 카테고리 안에 키워드를 수동으로 추가·삭제할 수 있다(검색창에 매번 타이핑하는 방식이 아니다).
- 선택한 카테고리에 등록된 모든 키워드를 기준으로 Google 뉴스 RSS를 검색해 뉴스 목록을 수집한다.
- 각 뉴스 항목은 제목, 원문 링크, 정리본을 보여준다.
- Anthropic API 키가 `.env`에 설정되어 있으면 AI가 정리본을 생성하고, 없으면 RSS 원문 설명을 정리본 자리에 표시한다.
- 뉴스가 없거나 요청이 실패하면 사용자가 이해할 수 있는 안내를 보여준다.
- 화면 구성은 `design/dashboard_preview.html`의 시각적 언어(다크 글래스 테마, 골드 악센트, 카테고리·키워드 매니저 패널 배치)를 따른다.
- 페이지 레이아웃은 프로토타입의 3단 그리드(270px/1fr/300px) 구조를 그대로 채택해, 앞으로 다른 패널이 하나씩 추가될 자리를 남겨둔다(왼쪽: 카테고리·키워드 매니저, 오른쪽: 뉴스, 가운데: 아직 미구현 안내).

## Acceptance criteria

- [ ] 카테고리를 추가하고, 그 안에 키워드를 여러 개 추가하면, 등록된 키워드들과 관련된 실제 뉴스가 목록으로 표시된다.
- [ ] 카테고리 안의 키워드를 삭제하면, 이후 뉴스 목록에 그 키워드로만 나온 결과가 더 이상 섞이지 않는다.
- [ ] 목록의 각 항목은 제목, 원문 링크, 정리본을 포함한다.
- [ ] 원문 링크를 열면 실제 뉴스 기사로 연결된다.
- [ ] `.env`에 Anthropic API 키가 없는 현재 상태에서도 에러 없이 목록과 정리본(원문 스니펫 대체)이 표시된다.
- [ ] 카테고리에 키워드가 하나도 없거나 관련 뉴스가 없으면, 빈 화면이나 깨진 화면 대신 이해할 수 있는 안내 문구가 표시된다.
- [ ] 카테고리를 새로고침 후에도 다시 열면 이전에 추가한 카테고리·키워드가 그대로 남아있다(브라우저 로컬 저장).

## Settled constraints and rationale

- 뉴스 소스는 Google 뉴스 RSS만 사용한다 — [docs/decisions/news-source-scope.md](../../decisions/news-source-scope.md) 참고.
- 정리본은 Anthropic API 키 유무에 따라 AI 요약과 원문 스니펫으로 갈린다 — [docs/decisions/ai-summary-generation.md](../../decisions/ai-summary-generation.md) 참고.
- 개인용 단일 사용자 도구이며, 공유·협업 기능은 다루지 않는다 (PRODUCT.md의 경계 계승).
- 키워드는 카테고리에 소속되며, 뉴스 수집은 상단 검색창의 즉석 검색이 아니라 카테고리에 등록된 키워드 전체를 기준으로 한다(사용자 정정 사항).

## Assumptions

- 카테고리·키워드는 서버 DB 없이 브라우저 `localStorage`에 저장한다(단일 사용자·단일 브라우저 전제와 일치, 추후 서버 저장으로 교체 가능).
- 정리본과 화면 문구는 한국어로 표시한다.
- 카테고리 하나당 뉴스 목록은 최대 10건 정도로 제한한다(페이지네이션 없음).
- 여러 키워드의 뉴스를 합칠 때 같은 링크는 중복 제거한다.
- 기존 `app/page.tsx` 자리(홈 화면)에 구현한다.

## Off-limits (and why)

- AI 추천 키워드 제안 + 승인 흐름(점선 테두리 제안 칩) — 사용자가 이번 슬라이스에서는 수동 추가/삭제만 원함. 카테고리·키워드 관리 자체가 검증되고 난 뒤 다룬다.
- LUMI 채팅, 지식 DB, LLM Wiki/Obsidian 그래프 연동 — 뉴스 수집이 먼저 끝까지 동작해야 그 위에 쌓을 수 있는 후속 기능이다.
- 트위터(X), 링크드인 검색 — `docs/decisions/news-source-scope.md`에 정리된 이유로 이번 범위에서 제외한다.
- `design/dashboard_preview.html`의 연구 동향 그래프·기술 동향 진행 단계·하단 독 내비게이션 — 이번 슬라이스는 카테고리·키워드 관리와 뉴스 수집 패널만 반영한다.

## Deferred

- 트위터(X)·링크드인 뉴스 소스 추가는 공식 API 접근 방법이 정리되면 다시 논의한다.
- AI 추천 키워드 제안 기능은 카테고리·키워드 수동 관리가 검증된 뒤 별도로 다룬다.
- 카테고리·키워드를 서버 측에 저장해 여러 기기에서 공유하는 것은 이번 범위 밖이다.

## Remaining risks

- Anthropic API 키가 아직 없어, AI 요약이 실제로 잘 동작하는지는 이번 세션에서 검증하지 못한다. 키가 준비되면 별도 확인이 필요하다.
- Google 뉴스 RSS 응답 구조가 예고 없이 바뀌면 파싱이 깨질 수 있다.
- 카테고리에 키워드가 여러 개 등록되면 키워드 수만큼 RSS 요청이 늘어나, 키워드가 많은 카테고리는 응답이 느려질 수 있다.
