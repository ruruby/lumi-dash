# Tech Progress Panel

## User-visible outcome

사용자가 카테고리를 선택하고 "기술 동향 분석하기"를 누르면, 그 카테고리에 등록된 키워드 각각의 기술 성숙도 단계(탐색·연구·프로토타입·상용화)와 그 근거가 실제 뉴스를 바탕으로 표시된다.

## Approved scope

- 센터 컬럼의 "연구·기술 동향" 자리를 두 카드로 나눈다: "연구 동향"(LLM Wiki 그래프, 계속 보류)과 "기술 동향"(이번에 구현).
- "기술 동향" 카드에는 선택된 카테고리의 키워드별로, 각 키워드의 최신 뉴스를 근거로 기술 성숙도 단계와 한 줄 근거를 보여준다. 전체를 아우르는 한 줄 AI 요약도 함께 보여준다.
- 단계는 디자인과 동일하게 탐색 → 연구 → 프로토타입 → 상용화 4단계이며, 4칸 진행 막대로 표시한다.
- 분석은 버튼을 눌렀을 때 실행한다(카테고리를 바꿀 때마다 자동으로 다시 돌리지 않는다).
- 분석에는 뉴스 요약·LUMI 채팅과 마찬가지로 로컬 `claude` CLI를 사용한다. 새로운 API 키나 결제는 추가하지 않는다.
- 카테고리가 없거나 키워드가 없으면, 분석 버튼 대신 안내 문구를 보여준다.
- `claude` CLI를 사용할 수 없으면(로컬 실행이 아니면), "로컬에서 실행할 때만 사용할 수 있어요" 안내를 보여준다.

## Acceptance criteria

- [ ] 카테고리를 선택하고 키워드가 있는 상태에서 "기술 동향 분석하기"를 누르면, 각 키워드의 단계·진행 막대·한 줄 근거가 표시된다.
- [ ] 근거 문구는 그 키워드의 실제 수집된 뉴스 제목을 반영한 내용이다(임의로 지어낸 내용이 아니다).
- [ ] 카테고리를 선택하지 않았거나 키워드가 없으면, 분석 버튼 대신 안내 문구가 표시된다.
- [ ] `claude` CLI를 사용할 수 없으면, "로컬에서 실행할 때만 사용할 수 있어요" 안내가 표시되고 에러 없이 동작한다.
- [ ] 분석 결과 파싱에 실패하거나 요청이 실패해도 화면이 깨지지 않고 안내 문구가 표시된다.
- [ ] "연구 동향" 자리는 계속 보류 상태 안내로 남아 있고, 실제 그래프나 Obsidian 연동은 만들지 않는다.

## Settled constraints and rationale

- 분석은 OpenAI/Anthropic API가 아니라 로컬 `claude` CLI로 수행한다 — [docs/decisions/local-claude-cli-runtime.md](../../decisions/local-claude-cli-runtime.md) 참고(이 결정은 LUMI 채팅뿐 아니라 이 패널에도 적용되도록 범위를 넓혔다).
- "연구 동향"(LLM Wiki·Obsidian 지식 그래프)은 실제로 연동할 Obsidian Vault가 없어 이번에도 보류한다.
- 개인용 단일 사용자 도구이며 분석 결과는 세션 동안만 유지한다(PRODUCT.md 경계 계승).

## Assumptions

- 키워드별 근거 뉴스는 해당 키워드로 별도 검색한 최신 뉴스 상위 몇 건을 사용한다(카테고리 전체 뉴스 목록과는 별개로 조회한다).
- 분석 결과는 컴포넌트 상태로만 유지하고, 카테고리를 바꾸면 초기화된다(영구 저장하지 않음).
- 단계는 고정된 4단계(탐색/연구/프로토타입/상용화)만 사용한다.
- 카드 스타일은 `design/dashboard_preview.html`의 "기술 동향" 카드를 따른다.

## Off-limits (and why)

- "연구 동향" LLM Wiki·Obsidian 지식 그래프 — 실제 연동할 Obsidian Vault가 없어 그대로 보류. (카테고리-키워드 관계로 대체한 그래프는 이후 `docs/specs/research-trend-graph/spec.md`에서 별도로 다뤘다.)
- 여러 카테고리를 한 화면에서 비교하는 것 — 이번엔 선택된 카테고리 하나만 다룬다.

## Deferred

- LLM Wiki·Obsidian 연동 그래프는 실제 연동 방법이 정해지면 별도로 다룬다.
- 분석 결과를 저장해뒀다가 카테고리 재방문 시 자동으로 다시 보여주는 것은 이후 논의한다.

## Remaining risks

- 로컬 `claude` CLI 호출이라 분석에 수 초~수십 초가 걸릴 수 있다(LUMI 채팅과 같은 제약).
- 이 기능도 `claude` CLI가 설치·로그인된 로컬 환경에서만 동작한다.
- 키워드 수가 많아지면 CLI 호출 한 번에 포함되는 컨텍스트가 길어져 응답이 느려지거나 일부 키워드가 누락될 수 있다.
