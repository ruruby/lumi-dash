# Derived Metrics Honesty

## Decisions

- 화면에 표시하는 수치(증감률, 신규 자료 수, 노트 수 등)는 실제 데이터에 담긴 값에서만 계산한다. 뉴스는 RSS `pubDate`, 노트는 파일 수정 시각과 frontmatter `updated`를 근거로 삼는다.
- 계산에 필요한 근거가 없으면 숫자를 추정하거나 지어내지 않고, 값 없음으로 표시한다.
- 추세는 최근 구간과 직전 동일 길이 구간의 실제 자료 수를 비교해 낸다.

## Boundaries

- 이 결정은 사용자에게 사실처럼 보이는 정량 표시에 적용된다. AI가 생성하는 서술형 요약은 대상이 아니며, 그쪽은 근거 자료를 함께 제시하는 방식으로 다룬다.

## Why

디자인 목업에는 `↑31%`, `14 new papers` 같은 숫자가 예시로 들어 있었다. 이 값들을 그대로 화면에 넣으면 사용자는 실제 측정값으로 읽지만, 앱에는 그것을 뒷받침할 이력 데이터가 없다. 개인용 연구 도구에서 가짜 수치는 잘못된 판단으로 직결되므로, 근거 없는 숫자를 보여주느니 값이 없다고 말하는 편이 낫다.

자료에 이미 들어 있는 타임스탬프만으로도 실제 추세를 계산할 수 있어, 이력 저장소 없이도 정직한 수치를 제공할 수 있다.

## Reconsider when

- 수집 시점 이력을 별도로 저장하게 되었을 때. 그때는 타임스탬프가 없는 자료에 대해서도 실제 추세를 계산할 수 있다.

## Still-rejected alternatives

- 디자인 목업의 예시 수치를 그대로 표시 — 측정값처럼 보이지만 근거가 없어 사용자를 오도함.
- 자료 수에서 그럴듯한 증감률을 추정해 표시 — 계산 근거가 사용자에게 드러나지 않아 마찬가지로 오도함.
