# News Source Scope

## Decisions

- 뉴스 수집은 1차로 Google 뉴스 RSS 검색만 사용한다. 트위터(X)와 링크드인 검색은 이번 범위에서 제외한다.

## Boundaries

- 이 결정은 "키워드 → 관련 뉴스 목록" 기능 전체에 적용된다. 향후 다른 뉴스 소스를 추가할 때도 먼저 이 문서를 확인한다.

## Why

트위터(X) API는 사실상 무료 검색 티어가 없고, 링크드인은 공개 검색 API가 없어 스크래핑에 의존해야 해 서비스 약관 위반 소지가 있다. 반면 Google 뉴스 RSS는 키 없이 바로 키워드 검색이 가능해, 첫 결과물을 한 번에 구현하고 실제 동작으로 검증하기에 적합하다.

## Reconsider when

- 트위터(X) 또는 링크드인의 공식 검색 API를 합법적으로 사용할 수 있는 방법(유료 계약 체결 등)이 확보되었을 때.

## Still-rejected alternatives

- Twitter/X 유료 API 계약 — 이번 슬라이스에서는 비용·설정 부담이 범위를 벗어남; 실제로 유료 계약을 맺기로 결정하면 재검토.
- 링크드인 스크래핑 — 약관 위반과 차단 위험이 있음; 공식 API가 열리면 재검토.
