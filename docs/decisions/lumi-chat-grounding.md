# LUMI Chat Grounding Source

## Decisions

- LUMI 채팅은 이번 슬라이스에서 별도의 문서·벡터 DB를 구축하지 않고, 사용자가 현재 선택한 카테고리에서 이미 수집된 뉴스 목록(제목·정리본·링크)을 그 자리에서 컨텍스트로 전달해 답변한다.

## Boundaries

- 이 결정은 LUMI 채팅 기능의 첫 구현 슬라이스에만 적용된다. 논문이나 축적 문서를 포함하는 실제 지식 DB로 확장할 때는 이 문서를 다시 검토한다.

## Why

사용자는 향후 논문 정보나 축적되는 문서를 기반으로 그라운딩을 확장하길 원하지만, 벡터 DB 등 실제 저장소를 지금 구축하면 한 번에 구현하고 검증하기 어려운 범위가 된다. 이미 수집된 뉴스를 그 자리에서 컨텍스트로 넘기는 방식은 추가 인프라 없이 채팅 기능 자체(질문 → 그라운딩된 답변)를 끝까지 동작시키고 검증할 수 있다.

## Reconsider when

- 논문·문서 등 뉴스 외의 자료를 누적 저장하고 검색할 필요가 실제로 생겼을 때, 또는 카테고리 하나의 뉴스만으로 답변 품질이 부족하다고 확인됐을 때.

## Still-rejected alternatives

- 벡터 DB 기반 지식 저장소 즉시 구축 — 문서 수집·임베딩·검색 인프라가 먼저 필요해 이번 슬라이스의 범위를 크게 넘어섬; 그라운딩 확장이 실제로 필요해지면 재검토.
