# 공급망 보안

내가 직접 쓰지 않은 코드가 내 제품에 들어오면서 생기는 위험 전반. 라이브러리, 빌드 도구, 컨테이너 베이스 이미지, 그리고 요즘은 모델 가중치까지 포함된다.

## 구성 요소

- 무엇이 들어있는지 안다 → [[SBOM]]
- 그중 진짜 위험한 걸 가린다 → [[VEX]]
- 빌드 과정이 조작되지 않았음을 증명한다 → 아직 내 노트가 없음

## AI 시대의 확장

모델도 공급망 자산이라는 관점이 생겼다. 모델 출처, 학습 데이터 이력, 파인튜닝 체인이 모두 추적 대상이 된다. [[AI Red Teaming]]과 만나는 지점이 여기다.

## 성숙도에 대한 내 판단

전통적인 코드 공급망은 **상용화** 단계다. 반면 모델 공급망은 이제 논의가 시작된 **탐색** 단계다. 같은 이름으로 묶여 있지만 성숙도 차이가 크다는 걸 잊으면 안 된다.
