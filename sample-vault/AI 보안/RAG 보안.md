# RAG 보안

검색 증강 생성 파이프라인에서, 검색해 온 문서가 신뢰할 수 없을 때 생기는 문제 전반. [[프롬프트 인젝션]]의 간접 인젝션이 여기서 현실이 된다.

## 위협 모델

내가 정리한 공격 경로는 셋이다.

- **오염된 문서 삽입** — 인덱싱 대상에 공격자가 문서를 넣을 수 있으면 끝이다.
- **검색 순위 조작** — 특정 질의에서 악성 문서가 상위에 오도록 유도한다.
- **출처 위장** — 신뢰할 만한 출처인 척하는 문서.

## 대응

검색 결과를 **데이터로만** 취급하도록 프롬프트 경계를 명확히 하고, 출처 신뢰도 점수를 랭킹에 반영한다. 인덱싱 파이프라인 자체의 접근 통제가 사실 가장 효과가 크다. 이건 [[공급망 보안]]과 문제 구조가 닮았다.
