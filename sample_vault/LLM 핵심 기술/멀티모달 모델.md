# 멀티모달 모델

멀티모달 모델은 텍스트뿐 아니라 이미지, 오디오, 비디오 같은 입력을 공통 표현 공간에서 처리한다. 화면 이해, 문서 분석, 음성 인터페이스처럼 텍스트만으로 해결하기 어려운 작업에 적합하다.

## 주요 쟁점

- 해상도가 높은 이미지와 긴 영상은 입력 토큰과 지연시간을 크게 늘린다.
- OCR 정확도와 시각적 추론 능력을 분리해 평가해야 한다.
- 이미지 속 작은 글자, 공간 관계, 시간 순서에서 오류가 자주 발생한다.
- 민감한 이미지와 음성은 저장 및 전송 정책을 먼저 정해야 한다.

## 연결

시각 토큰을 처리하는 방식은 [[Transformer 아키텍처]]와 연결된다. 실제 제품에서는 텍스트 평가 세트만 재사용할 수 없으므로 [[LLM 평가]]에 화면·문서·음성별 기준을 추가해야 한다. 큰 입력 비용은 [[효율적인 추론]]의 핵심 과제다.
