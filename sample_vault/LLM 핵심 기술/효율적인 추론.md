# 효율적인 추론

효율적인 추론은 정확도를 유지하면서 응답 지연, GPU 메모리, 처리 비용을 줄이는 작업이다. 모델 크기만 줄이는 것이 아니라 요청 배치, KV cache, 양자화, speculative decoding을 함께 본다.

## 적용 후보

- 8bit·4bit 양자화: 메모리를 줄이지만 모델과 작업에 따라 품질 저하가 다르다.
- Continuous batching: 여러 요청을 동적으로 묶어 처리량을 높인다.
- Prefix caching: 반복되는 시스템 프롬프트 계산을 재사용한다.
- Speculative decoding: 작은 모델이 후보 토큰을 제안하고 큰 모델이 검증한다.

## 실험 계획

[[로컬 모델 실행]] 환경에서 동일한 프롬프트 세트로 TTFT, tokens/sec, 최대 메모리, 답변 품질을 기록한다. 최적화 전후의 품질 회귀는 [[LLM 평가]]로 확인한다. 구조적 배경은 [[Transformer 아키텍처]]를 참고한다.
