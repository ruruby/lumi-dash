# 에이전트 시스템

LLM 에이전트는 모델이 목표를 해석하고 도구를 선택하며 실행 결과를 다음 판단에 반영하는 시스템이다. 핵심은 자율성 자체가 아니라 상태, 권한, 실패 복구를 명시적으로 설계하는 데 있다.

## 구성 요소

- Planner: 목표를 실행 가능한 단계로 나눈다.
- Tool layer: 검색, 코드 실행, 외부 API처럼 허용된 행동을 제공한다.
- Memory: 현재 작업 상태와 장기 지식을 구분해 저장한다.
- Evaluator: 결과가 목표와 제약을 만족하는지 판단한다.

## 설계 판단

긴 자율 루프보다 짧은 계획-실행-검증 루프가 오류 위치를 찾기 쉽다. 비용이 크거나 되돌리기 어려운 행동에는 사람의 승인을 둔다. 프레임워크 선택은 [[LLM 오케스트레이션]]에서 비교하고, 실제 작업 성공률은 [[LLM 평가]]로 측정한다.
