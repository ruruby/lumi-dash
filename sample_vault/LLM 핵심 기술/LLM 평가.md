# LLM 평가

LLM 평가는 모델의 일반 능력보다 실제 사용 흐름이 성공하는지를 반복 가능하게 측정해야 한다. 정확성, 근거성, 작업 완료율, 지연시간, 비용을 함께 기록한다.

## 평가 계층

1. 구성 요소 평가: 검색 recall, reranker 정확도, tool schema 준수율
2. 시나리오 평가: 사용자의 대표 과업을 처음부터 끝까지 완료하는지 확인
3. 운영 평가: 실제 실패 사례와 사용자 피드백을 회귀 세트로 편입

[[검색 증강 생성]]은 검색과 답변 근거성을 분리하고, [[에이전트 시스템]]은 최종 성공뿐 아니라 도구 선택과 복구 과정을 추적한다. [[멀티모달 모델]]은 입력 유형마다 별도 기준이 필요하다.

## 현재 판단

단일 점수로 모델을 고르기보다 실패 유형별 임계값을 두는 것이 낫다. 평가 결과와 실행 trace는 [[LLM 관측성]]에서 함께 조회할 수 있어야 한다.
