# 검색 증강 생성

검색 증강 생성(RAG)은 질문과 관련된 외부 문서를 검색해 모델의 문맥에 넣는 방식이다. 모델 재학습 없이 최신 정보와 조직 내부 지식을 활용할 수 있지만, 검색 실패와 생성 실패를 분리해서 다뤄야 한다.

## 기본 파이프라인

1. 문서를 의미 단위로 나누고 임베딩을 생성한다.
2. 질문과 가까운 후보를 검색한다.
3. reranker로 실제 관련성이 높은 문서를 다시 정렬한다.
4. 출처와 함께 답변하도록 생성 프롬프트를 구성한다.

## 설계 메모

고정 길이 chunk는 구현이 쉽지만 표와 절차의 의미를 끊을 수 있다. hybrid search와 metadata filter는 정확도를 높이지만 운영 복잡도도 증가시킨다. 검색 결과를 무조건 신뢰하지 않고 답변 근거를 노출해야 한다.

## 연결

검색 저장소는 [[벡터 데이터베이스]]와 연결되고, 검색·생성 단계의 실패는 [[LLM 평가]]에서 별도 지표로 측정한다. 도구 호출까지 확장하면 [[에이전트 시스템]]의 지식 도구가 된다.
