# 코딩 에이전트

코딩 에이전트는 저장소를 탐색하고 파일을 수정하며 명령을 실행해 개발 작업을 완수한다. 코드 생성 품질만큼 변경 범위 통제, 기존 작업 보존, 실행 결과 검증이 중요하다.

## 효과적인 작업 루프

1. 저장소 지침과 관련 코드를 읽는다.
2. 목표와 수용 기준을 작은 실행 단위로 좁힌다.
3. 변경 후 타입 검사와 실제 런타임 흐름을 확인한다.
4. diff에서 범위 밖 변경과 사용자 작업 훼손 여부를 검토한다.

복잡한 작업 흐름은 [[LLM 오케스트레이션]]으로 모델링할 수 있다. 명령 실행과 파일 변경 trace는 [[LLM 관측성]]에 남기고, 대표 저장소 과업은 [[LLM 평가 자동화]]로 반복 측정한다.
