# LLM 평가 자동화

LLM 평가 자동화는 프롬프트나 모델이 바뀔 때 대표 과업의 품질 회귀를 빠르게 찾는 도구 체계다. 정답 일치만으로 판단하기 어려우므로 규칙 기반 검사, 모델 채점, 사람 검토를 위험도에 맞게 조합한다.

## 실행 원칙

- 실제 실패 사례를 작고 설명 가능한 데이터셋으로 유지한다.
- 비결정성을 고려해 단일 실행보다 반복 분포를 본다.
- 채점 프롬프트와 채점 모델 버전을 함께 기록한다.
- 품질, 지연시간, 비용을 같은 실행에서 수집한다.

[[LLM 관측성]]에서 수집한 실패 trace를 회귀 세트 후보로 만들고, [[LLM 오케스트레이션]]의 단계별 결과도 평가한다. [[벡터 데이터베이스]] 변경 시에는 검색 recall과 최종 답변 품질을 모두 비교한다.
