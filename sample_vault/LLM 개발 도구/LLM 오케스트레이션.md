# LLM 오케스트레이션

LLM 오케스트레이션 도구는 프롬프트, 모델 호출, 검색, 도구 실행을 재사용 가능한 흐름으로 묶는다. 단순 체인에는 얇은 함수 조합이 충분하고, 분기·재시도·사람 승인이 필요한 경우 상태 그래프가 유리하다.

## 도구 선택 기준

- 실행 상태를 저장하고 중단 지점에서 재개할 수 있는가
- 각 단계의 입력·출력과 비용을 추적할 수 있는가
- 특정 모델이나 벡터 저장소에 과도하게 결합되지 않는가
- 실패한 단계만 재실행할 수 있는가

LangGraph 같은 상태 그래프는 복잡한 [[코딩 에이전트]]와 잘 맞지만 작은 기능에는 학습 비용이 크다. 어떤 방식을 택하든 [[LLM 관측성]]을 먼저 연결하고 [[LLM 평가 자동화]]로 회귀를 막아야 한다.
