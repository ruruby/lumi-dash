# 벡터 데이터베이스

벡터 데이터베이스는 임베딩 근접 검색과 metadata filter를 제공해 RAG의 검색 계층을 구성한다. 제품 선택보다 데이터 갱신 방식, 삭제 일관성, 검색 품질 측정이 더 중요하다.

## 비교 항목

- ANN index 종류와 recall·latency 균형
- keyword와 vector를 결합하는 hybrid search 지원
- 문서 단위 권한 필터와 tenant 격리
- 증분 색인, 백업, 지역 배치 방식

초기 프로토타입은 애플리케이션이 이미 사용하는 데이터베이스의 vector 확장을 우선 검토한다. 규모나 검색 요구가 커질 때 전문 제품으로 이동한다. 검색 trace는 [[LLM 관측성]]으로 확인하고 결과 품질은 [[LLM 평가 자동화]]에 연결한다.
