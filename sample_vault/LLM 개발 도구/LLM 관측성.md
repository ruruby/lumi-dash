# LLM 관측성

LLM 관측성은 한 요청에서 사용한 프롬프트, 모델, 검색 문서, 도구 호출, 지연시간, 토큰 비용을 trace로 연결한다. 로그 수집 자체보다 실패 원인을 재현하고 평가 데이터로 되돌리는 순환 구조가 목적이다.

## 필요한 데이터

- trace와 span 식별자
- 모델·프롬프트 버전
- 검색 query와 반환 문서 ID
- 도구 입력·출력 및 오류
- TTFT, 전체 지연시간, 입력·출력 토큰
- 사용자 피드백과 평가 결과

민감한 원문을 그대로 저장하지 않도록 필드별 마스킹과 보존 기간을 둔다. [[LLM 오케스트레이션]]의 각 실행 단계를 span으로 만들고, 실패 trace를 [[LLM 평가 자동화]]의 회귀 사례로 전환한다.
