# 로컬 모델 실행

로컬 모델 실행은 데이터 통제, 오프라인 사용, 예측 가능한 비용이 중요한 환경에서 유용하다. Ollama는 개발 경험이 단순하고, llama.cpp는 다양한 하드웨어와 양자화 형식을 지원하며, vLLM은 서버 처리량 최적화에 강점이 있다.

## 선택 기준

- 개인 개발: 설치와 모델 교체가 쉬운 런타임
- 엣지 환경: CPU·통합 메모리에서의 양자화 성능
- 팀 서비스: continuous batching과 OpenAI 호환 API
- 규제 데이터: 모델 파일과 요청 로그의 저장 위치

실험 결과는 모델 이름만 적지 않고 quantization, context length, batch size, 하드웨어를 함께 기록한다. 성능 비교는 [[LLM 평가 자동화]]로 품질을 고정하고 [[LLM 관측성]]으로 지연 구간을 분석한다.
